# 1. Two Sum
- Сложность: Easy
- Ссылка: https://leetcode.com/problems/two-sum/

## Условие
Дан массив целых чисел `nums` и число `target`.

Необходимо найти два разных элемента, сумма которых равна `target`,
и вернуть их индексы. Гарантируется, что правильный ответ существует
и является единственным.

## Описание решения
Для хранения уже просмотренных чисел используется контейнер map. Ключом является число из массива, а значением - его индекс: число - индекс

Во время прохода по массиву:
1. В переменную x записывается текущее число.
2. Вычисляется число y, которое необходимо добавить к x, чтобы получить target: y = target - x
3. Проверяется, встречалось ли число y раньше.
4. Если y найдено в position, возвращаются его индекс и индекс текущего числа.
5. Если y не найдено, текущее число x сохраняется вместе с его индексом.
