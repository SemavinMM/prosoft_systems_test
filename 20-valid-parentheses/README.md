# 20. Valid Parentheses

- Сложность: Easy
- Ссылка на задачу: https://leetcode.com/problems/valid-parentheses/

## Условие

Дана строка `s`, состоящая из круглых `()`, квадратных `[]` и фигурных `{}` скобок.

Нужно определить, является ли последовательность скобок правильной.

Последовательность считается правильной, если каждая открывающая скобка имеет закрывающую скобку такого же типа, а все скобки закрываются в правильном порядке.

Например:

- `()` — правильная последовательность;
- `()[]{}` — правильная последовательность;
- `(]` — неправильная последовательность;
- `([)]` — неправильная последовательность;
- `([])` — правильная последовательность.

## Идея решения

Для хранения открывающих скобок используется стек `openedBrakets`.
Стек работает по принципу: последняя добавленная скобка должна закрыться первой.
Алгоритм проходит по всем символам строки:

1. Если текущий символ `current` является открывающей скобкой, он добавляется в стек.
2. Если встретилась закрывающая скобка, а стек пуст, возвращается `false`, потому что для неё нет соответствующей открывающей скобки.
3. Если стек не пуст, из него берётся последняя открывающая скобка `lastOpened`.
4. В переменной `braketsClose` проверяется, соответствуют ли открывающая и закрывающая скобки друг другу.
5. Если скобки не соответствуют друг другу, возвращается `false`.
6. Если скобки образуют правильную пару, открывающая скобка удаляется из стека.
7. После обработки строки проверяется, остались ли в стеке незакрытые скобки. Если стек пуст, последовательность является правильной.

## Пример работы

Рассмотрим строку: `([])`

- Символ `(` добавляется в стек.
- Символ `[` добавляется в стек.
- Символ `]` соответствует последней открывающей скобке `[`, поэтому она удаляется.
- Символ `)` соответствует оставшейся скобке `(`, поэтому она тоже удаляется.
- После обработки строки стек пуст, значит результат равен `true`.
