# 49. Group Anagrams
- Сложность: Medium
- Ссылка на задачу: https://leetcode.com/problems/group-anagrams/

## Условие

Дан массив строк `strs`.
Необходимо объединить в отдельные группы слова, являющиеся анаграммами друг друга. Порядок групп и слов внутри них не имеет значения.
Анаграммы - это слова, которые состоят из одинаковых букв в одинаковом количестве, но могут иметь разный порядок букв.
Например, слова `eat`, `tea` и `ate` являются анаграммами.

## Идея решения

Если отсортировать буквы в словах-анаграммах, получится одинаковая строка:
eat - aet
tea - aet
ate - aet

В решении используется хеш-таблица groups:
- ключ - отсортированная версия слова
- значение -список исходных слов, которые соответствуют этому ключу

Таким образом, все анаграммы автоматически попадают в одну группу.

## Алгоритм

Для каждого слова из массива:

1. Исходное слово сохраняется в переменной word
2. Создаётся его копия sortWord
3. Символы в sortWord сортируются с помощью функции sort()
4. Исходное слово добавляется в groups[sortWord]

После обработки всех слов создаётся массив result. Каждая сформированная группа group.second переносится из хеш-таблицы groups в result. После этого result возвращается в качестве ответа.
