# 3. Longest Substring Without Repeating Characters

- Сложность: Medium
- Ссылка: https://leetcode.com/problems/longest-substring-without-repeating-characters/

## Условие

Дана строка `s`.
Необходимо найти длину самой длинной непрерывной подстроки, в которой символы не повторяются.
Например, для строки `abcabcbb` самой длинной подстрокой без повторений может быть `abc`. Её длина равна `3`.

## Идея решения

Для решения используется метод скользящего окна.
Границы текущей подстроки задаются двумя переменными:
- `left` - индекс первого символа
- `right` - индекс последнего символа

Множество `usedCharacters` хранит символы, находящиеся внутри текущего окна.
Указатель `right` постепенно перемещается вправо. Если очередной символ уже находится в множестве, левая граница `left` сдвигается вправо. Одновременно символы удаляются из множества до тех пор, пока повторение не исчезнет.
После этого текущий символ добавляется в множество, а длина окна сравнивается с максимальной найденной длиной.

## Алгоритм

1. Создать пустое множество `usedCharacters`.
2. Установить левую границу `left` в начало строки.
3. Перемещать правую границу `right` по строке.
4. Записать текущий символ в переменную `current`.
5. Пока `current` уже находится в множестве:
   - удалить из множества символ `s[left]`
   - увеличить `left`
6. Добавить `current` в множество.
7. Вычислить длину текущей подстроки: `currentLength = right - left + 1`
8. Если `currentLength` больше `maxLength`, обновить максимальную длину.
9. После обработки всей строки вернуть `maxLength`.
